# Solara Bay

An original third-person open-world crime game in a sun-soaked coastal city. Steal a ride, explore the waterfront, outdrive the police, and follow five story missions from your first wheels to a final lighthouse escape. Includes traffic, pedestrians, pistol combat, a live minimap, synthesized audio, and local saves. All art is generated in the game; Three.js is bundled locally.

## Run it

Run `node serve.ts`, then open http://127.0.0.1:8080 in a desktop browser. No install or build is needed.

WASD moves or drives; Shift runs; mouse orbits; E enters or exits a car; Space brakes; click fires; R reloads; Esc pauses. Use Save in the pause menu to keep your progress.
