# Solara Bay

[![Competition: gta6-01](https://img.shields.io/badge/make.fun-gta6--01-f2c94c)](https://make.fun/bounty/gta6-01) [![Repo](https://img.shields.io/badge/repo-piningit23%2Fsolara--bay-1d7a8c)](https://github.com/piningit23/solara-bay)

Solara Bay is an original open-world crime game set in a warm coastal city. Walk the grid, steal colorful cars, lose the heat, take contracts across the docks, and become the name on the lighthouse.

## Run it

```bash
node serve.ts
```

Open `http://127.0.0.1:8080`. The game is static and uses the vendored Three.js module. Start a run, then use WASD, Shift, E, mouse click, R, and Esc.
